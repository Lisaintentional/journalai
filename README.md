# Blue Training Quiz App

Simple static quiz funnel app for dog training lead generation and affiliate monetization.

## Run locally

Open `index.html` in a browser.

## What it does

- Asks 7 behavior questions
- Computes a training profile
- Shows a 14-day focus suggestion
- Displays Amazon-ready recommendation links
- Saves lead form submissions to browser `localStorage` (demo only)
